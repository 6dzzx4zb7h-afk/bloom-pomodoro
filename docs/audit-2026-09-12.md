# App audit — September 12, 2026

Reviewed the shared web app, state and persistence, audio and animation, iOS native controls and
commands, Android notifications, build wiring, and active project documentation. This records
findings and verification; it is not a future-feature checklist.

## Confirmed defects repaired

| Area | Trigger and correction | Evidence |
| --- | --- | --- |

## Requested simplifications

Removed the extra `UIVisualEffectView` / `UIGlassEffect` wrapper around the upper selectors.
They now use standard `UISegmentedControl` appearance, with explicit light/dark theme propagation.
The bottom `UITabBar` and standard Settings button remain system controls. The first plain-control
trial exposed dark-theme label contrast, which the explicit theme propagation addressed.

Removed backup/import/export, CSV export, recovery-file downloads, related UI, merge logic, tests,
and unused styles. Normal saving, schema migrations, save-error retry, and explicit local recovery
remain. Android already disables cloud and device-transfer backups. iOS now excludes Documents
and Library; actual iOS Simulator Foundation reads confirmed both exclusion flags are true.
[Apple describes these flags as backup guidance](https://developer.apple.com/documentation/foundation/optimizing-your-app-s-data-for-icloud-backup),
so they do not erase backups or exported files that already exist elsewhere.

The README, CLAUDE, and AGENTS guidance were rewritten by an explicitly requested Astra agent at
max reasoning. Old blanket product restrictions, plan gates, and mandatory historical-policy
references were removed. ROADMAP contains only an owner placeholder, without a prefilled checklist.

## Verification limits

Physical-device background cues, Silent Mode/Focus behavior, safe areas, spoken accessibility,
older supported OS versions, and installation over newer saved schemas are not validated by this
audit. Simulator screenshots and builds are not a release-readiness claim.

## Follow-up: study prompts and rendering (September 13)

Three Astra agents at high reasoning traced the before/during/after-study prompts, their
defaults, choice handlers, saved effects, and presentation order. The current-behavior reference
is [Bloom's study prompts](study-prompts.md); it is not a feature checklist.

The follow-up repaired these defects and confusing behaviors:

- Pet canvases measured CSS-transformed dimensions, cropping feet in compact timer rings.
  Drawing now uses the untransformed layout size, fits every pet's motion inside its canvas,
  and responds to size changes. Bounds coverage exercises six pets, all four poses, four
  canvas sizes, and reduced motion.
- Prompt backgrounds are opaque so underlying study text does not show through. Long cards
  can scroll inside the viewport instead of losing their lower controls.
- Recovery wording explains the interruption, optional next step, and resume/dismiss actions.
  A stale recovery action cannot overwrite newer running or paused Focus, Tiny, or Flow work,
  or a running break.
- Recovering a paused countdown used rounded history minutes and could change its seconds.
  New interruptions retain exact displayed seconds without a new saved format. Already-rounded
  historical records cannot regain lost precision. Exhausted interruptions no longer create
  artificial one-second sessions.
- Check-ins have an explicit “not now” action. It logs one skip and suppresses the next
  scheduled cycle without labeling the answer focused or drifted.
- Session intention can be disabled with Companion off. Pre-slump requirements and the
  return-question minimum of 45 seconds are explained in both Settings presentations.
- Ritual skip accurately says “skip & start”. Drift recovery says the timer keeps running
  and “save step & close”. Abandonment copy acknowledges its saved record.
- The fresh-session screen hides task context when there is no selected task and removes
  unexplained cycle dots. “What will you work on?” replaces the vague target label, with
  “e.g. answer 5 questions” as its example. Start works with everything left blank.
- “Plan for distractions” opens the existing saved if–then planner directly, removing the
  redundant “a little more prep” expansion. It explains the written response and opens for
  reading without immediately raising the keyboard. The scrolling header respects the top
  safe area.
- Automatic weekly review waits for five eligible sessions and no unfinished work; manual
  access remains. All weekly analyses use the same fresh review-open time, avoiding omitted
  sessions from earlier that day and unnecessary impure-render warnings.
- Closing a pending goal-credit question explicitly declines credit and stays dismissed.
  Cycling daily targets works even when another target is armed.

Follow-up checks: **75 files / 753 tests passed**, production build passed, and ESLint reported

Safari exercised onboarding, full rabbit rendering in day/night themes, interrupted-session
